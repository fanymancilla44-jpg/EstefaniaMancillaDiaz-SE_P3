# Adivina Quien One Piece

Proyecto de la Practica 3 de Sistemas Expertos.

Este juego simula un Adivina Quien con personajes de One Piece usando reglas, casos y encadenamiento hacia adelante.

## Herramientas
- HTML
- CSS
- JavaScript
- Visual Studio Code
- GitHub

## Funcionamiento
El usuario responde preguntas de si o no y el sistema intenta adivinar el personaje.
